# КР104 · вариант 5

**Исследование безопасности и удобства двухэтапного входа в систему**

Консольная программа на C++17 сравнивает вход по паролю и вход по паролю с одноразовым кодом. Для каждого из девяти сочетаний условий она моделирует по 1 000 000 независимых попыток на каждого участника и способ защиты. Всего получается 36 000 000 попыток.

## Запуск в Windows

В PowerShell из папки проекта выполните:

```powershell
.\bin\kr104.exe
.\bin\kr104.exe --test
.\bin\kr104.exe --csv results.csv
```

Первая команда печатает таблицу. Вторая проверяет все четыре сочетания знания пароля и прохождения второго этапа. Третья сохраняет новую копию таблицы в CSV с точкой в качестве десятичного разделителя.

## Сборка из исходника

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -static -s main.cpp -o kr104.exe
.\kr104.exe --test
```

В Linux с GCC:

```bash
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o kr104
./kr104 --test
./kr104 --csv results.csv
```

Программа использует стандартную библиотеку C++ и фиксированное начальное значение генератора `104005`. Показатели в консоли приведены в процентах. Столбцы `Password leaked` и `Owner code failed` содержат параметры эксперимента. Остальные четыре столбца показывают доли успешных входов.

## Результат

По модели вероятность чужого входа снижается с `p` до `p × 0,001`, где `p` — вероятность компрометации пароля. При этом вероятность входа владельца меняется со 100% до 100%, 90% или 80% в зависимости от частоты неудач на втором этапе. В выполненном прогоне с кодом посторонний вошёл от 12 до 101 раза на миллион попыток в зависимости от сочетания параметров.
