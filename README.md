# КР104 · вариант 5

**Исследование безопасности и удобства двухэтапного входа в систему**

Программа на C++17 сравнивает два способа входа. Первый — только по паролю, второй — по паролю и одноразовому коду. Мы проверяем, как часто может войти владелец и как часто — посторонний. Для каждого из девяти сочетаний условий программа проверяет по миллиону попыток для каждого участника и способа входа. Всего получается 36 000 000 попыток.

## Запуск в Windows

В PowerShell из папки проекта выполните:

```powershell
.\bin\kr104.exe
.\bin\kr104.exe --test
.\bin\kr104.exe --csv results.csv
```

Первая команда печатает таблицу. Вторая проверяет все четыре сочетания знания пароля и прохождения второго этапа. Третья сохраняет новую копию таблицы в CSV с точкой в качестве десятичного разделителя.

## Сборка из исходника

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic -static -s main.cpp -o kr104.exe
.\kr104.exe --test
```

В Linux с GCC:

```bash
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o kr104
./kr104 --test
./kr104 --csv results.csv
```

Генератор случайных чисел начинает со значения `104005`. Поэтому готовый файл `bin/kr104.exe` при повторном запуске выдаёт тот же CSV. Если собрать программу с другой стандартной библиотекой C++, отдельные числа могут отличаться.

Показатели в консоли приведены в процентах. Столбцы `Password leaked` и `Owner code failed` содержат параметры эксперимента. Остальные четыре столбца показывают доли успешных входов.

## Результат

По расчётам с кодом посторонний входит в 1000 раз реже. В нашей таблице получилось от 9 до 110 чужих входов с кодом на миллион попыток. Владелец входит по паролю в 100% случаев. Если нужен код, при отказах в 0%, 10% и 20% попыток получается около 100%, 90% и 80% успешных входов.
